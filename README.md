# Title: Insurance Contact Centre Performance Analysis

# Overview
This project analyses an insurance contact centre that uses Amazon Connect to make calls. It uses the contact centre data to identify factors contributing to abandoned calls, missed calls, and operational inefficiencies.

Using PostgreSQL and SQL, the data was cleaned, validated, and analysed to generate actionable business recommendations aimed at improving customer experience and contact centre performance.

# Business Problem

Management identified:
- High abandoned call rates
- Increased missed calls
- Long customer wait times
- Uneven agent performance

The objective was to determine the root causes and recommend operational improvements.

# Key Findings
- Total Calls: 999
- Answered Calls: 734
- Abandoned Calls: 180
- Missed Calls: 85
- Abandonment Rate: 18%
- Missed Call Rate: 8.5%
  
# Recommendations
- Increase staffing during peak periods
- Monitor high missed-call agents
- Implement real-time queue monitoring
- Introduce callback functionality
- Improve workforce planning
